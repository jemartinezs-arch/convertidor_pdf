# PDF Converter Web App

Aplicación web desarrollada con Flask que permite convertir archivos PDF a otros formatos como Word y PNG.

## Tecnologías utilizadas

- Python
- Flask
- HTML
- CSS

## Funcionalidades

- Conversión de PDF a Word
- Conversión de PDF a PNG
- Descarga automática de archivos convertidos

## Próximas mejoras

- Sistema de login con SQLite
- Historial de conversiones
- Mejoras en interfaz de usuario

## Cómo ejecutar el proyecto

1. Clonar el repositorio

git clone https://github.com/jemartinezs-arch/nombre-del-repo.git

2. Instalar dependencias

pip install -r requirements.txt

3. Ejecutar la aplicación

python app.py
